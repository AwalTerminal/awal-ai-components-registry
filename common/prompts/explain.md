# Explain Code

Explain the selected code or file in detail:

1. **Purpose**: What does this code do at a high level?
2. **How it works**: Walk through the logic step by step
3. **Key concepts**: Explain any patterns, algorithms, or non-obvious techniques used
4. **Dependencies**: What does it depend on? What depends on it?
5. **Potential issues**: Any edge cases, performance concerns, or bugs?

Keep the explanation concise but thorough. Use examples where helpful.
