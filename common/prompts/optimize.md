# Optimize

Analyze the code for performance improvements:

1. **Identify bottlenecks**: Look for O(n^2) operations, unnecessary allocations, redundant computations
2. **Suggest improvements**: Provide concrete changes with before/after examples
3. **Measure impact**: Estimate the improvement (big-O, memory, latency)
4. **Trade-offs**: Note any readability or maintainability trade-offs

Focus on impactful optimizations, not micro-optimizations. Profile-guided suggestions are preferred over guesses.
