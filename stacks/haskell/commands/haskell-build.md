# Haskell Build & Test

Run with stack or cabal:
- `stack build` — compile the project
- `stack test` — run all test suites
- `stack run` — build and run the executable
- `stack ghci` — open a REPL with project modules loaded
- `cabal build all` — compile with cabal
- `cabal test all` — run tests with cabal
- `hlint src/` — run the linter on source files
- `ormolu --mode check src/**/*.hs` — check formatting
