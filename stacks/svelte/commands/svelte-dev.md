# Svelte Dev & Build

Run with SvelteKit or Vite:
- `npm run dev` -- start SvelteKit/Vite dev server with hot reload
- `npm run dev -- --open` -- start dev server and open browser
- `npm run build` -- build for production (adapter-dependent output)
- `npm run preview` -- preview the production build locally
- `npx svelte-check` -- type-check and lint all Svelte + TS files
- `npx svelte-check --watch` -- type-check in watch mode
- `npx vitest` -- run unit and component tests
- `npx vitest --coverage` -- run tests with coverage report
- `npx vitest --ui` -- open Vitest browser UI
- `npx playwright test` -- run E2E tests with Playwright
- `npx playwright test --ui` -- open Playwright test runner UI
- `npx prettier --check .` -- check formatting
- `npx prettier --write .` -- auto-format all files
- `npx eslint .` -- lint with eslint-plugin-svelte
