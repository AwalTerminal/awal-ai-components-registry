# Vue Dev & Build

Run with Vite or Nuxt:
- `npm run dev` -- start Vite/Nuxt dev server with HMR
- `npm run build` -- build for production
- `npm run preview` -- preview production build locally
- `npx vue-tsc --noEmit` -- type-check all Vue SFCs and TS files
- `npx nuxi dev` -- start Nuxt development server
- `npx nuxi build` -- build Nuxt for production
- `npx nuxi generate` -- generate static site with Nuxt
- `npx nuxi prepare` -- generate Nuxt types (.nuxt/tsconfig.json)
- `npx vitest` -- run unit and component tests
- `npx vitest --coverage` -- run tests with coverage report
- `npx vitest --ui` -- open Vitest browser UI
- `npx eslint .` -- lint all files
- `npx prettier --check .` -- check formatting
- `npx prettier --write .` -- auto-format all files
- `npx playwright test` -- run E2E tests with Playwright
- `npx storybook dev` -- start Storybook for component development
