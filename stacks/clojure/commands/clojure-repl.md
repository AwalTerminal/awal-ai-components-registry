# Clojure REPL & Build

Run with Leiningen or Clojure CLI:
- `clj` — start a REPL with deps.edn
- `clj -X:test` — run tests (with test alias configured)
- `lein repl` — start a Leiningen REPL
- `lein test` — run all tests
- `lein uberjar` — build a standalone JAR
- `clj-kondo --lint src/` — run the linter
- `cljfmt check` — check formatting
