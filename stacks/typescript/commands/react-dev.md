# React Dev & Build (TypeScript)

Run with Vite, Next.js, or CRA:
- `npm run dev` / `npx vite` -- start Vite dev server with HMR
- `npm run build` / `npx vite build` -- production build
- `npm run preview` / `npx vite preview` -- preview production build locally
- `npx next dev` -- start Next.js dev server
- `npx next build` -- production build (Next.js)
- `npx vitest` -- run tests with Vitest
- `npx vitest --coverage` -- run tests with coverage report
- `npx vitest --ui` -- open Vitest browser UI
- `npx jest` -- run tests with Jest (if configured)
- `tsc --noEmit` -- type-check without emitting
- `npx eslint .` -- lint all files
- `npx prettier --check .` -- check formatting
- `npx prettier --write .` -- auto-format all files
- `npx storybook dev` -- start Storybook for component development
- `npx playwright test` -- run E2E tests with Playwright
