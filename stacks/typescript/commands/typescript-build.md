# TypeScript Build & Test

Run with tsc and common tools:
- `tsc --noEmit` — type-check without emitting files
- `tsc --build` — compile the project
- `npx vitest` — run tests with Vitest
- `npx vitest --coverage` — run tests with coverage
- `npx eslint .` — lint all files
- `npx prettier --check .` — check formatting
- `npx prettier --write .` — auto-format all files
- `npx tsc --watch` — type-check in watch mode
