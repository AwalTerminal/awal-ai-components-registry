# F# Build & Test

Run with dotnet CLI:
- `dotnet build` — compile the project
- `dotnet test` — run all tests
- `dotnet run` — build and run the default project
- `dotnet fsi script.fsx` — run an F# script
- `dotnet watch test` — re-run tests on file changes
- `dotnet publish -c Release` — build for production
- `fantomas --check .` — check formatting
- `dotnet format` — auto-fix formatting issues
