# Lua Run & Test

Run with lua or luarocks:
- `lua script.lua` — run a script
- `luajit script.lua` — run with LuaJIT
- `busted` — run tests (busted test framework)
- `busted --verbose` — run tests with detailed output
- `luacheck .` — lint all Lua files
- `luarocks install --deps-only rockspec.rockspec` — install dependencies
- `luarocks make` — build and install the local rock
