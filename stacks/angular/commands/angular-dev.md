# Angular Dev & Build

Run with Angular CLI:
- `ng serve` — start development server with live reload
- `ng build` — build for production
- `ng test` — run unit tests with Karma/Jest
- `ng test --watch=false --code-coverage` — run tests once with coverage
- `ng lint` — lint all files
- `ng generate component features/my-feature` — scaffold a new component
- `ng e2e` — run end-to-end tests
- `npx prettier --write .` — auto-format all files
