# React Native Dev & Build

Run with Expo or React Native CLI:
- `npx expo start` — start Metro bundler with Expo
- `npx expo run:ios` — build and run on iOS simulator
- `npx expo run:android` — build and run on Android emulator
- `npx react-native run-ios` — build with bare React Native
- `npx jest` — run tests
- `npx jest --coverage` — run tests with coverage
- `npx eslint .` — lint all files
- `npx eas build --platform ios` — build for production with EAS
